% option reach a \usepackage line the template marks DO NOT CHANGE.
%
% The option handles the author block and nothing else. Anything else that
% identifies us -- acknowledgements, a repository URL, "our earlier work" --
% has to go by hand. See SUBMISSION_CHECKLIST.md before sending.
